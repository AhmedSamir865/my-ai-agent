# وكيل التطوير المحلي — PWA

تطبيق FastAPI بواجهة عربية RTL، مناسبة للهاتف وقابلة للتثبيت كتطبيق PWA. يدعم محادثة متعددة المزودات، تنفيذ خطة آلية محدودة، بحث ويب واستخراج صفحات، إصلاحاً ذاتياً محدوداً، محرراً وطرفية ومعاينة، ونشراً إلى Vercel بعد تأكيد.

## الواجهة الهاتفية وPWA

- شريط تنقل سفلي للمحادثة والمهام والأكواد/المتصفح والمعاينة والإعدادات.
- `manifest.json` وأيقونات 192/512 وService Worker.
- لتثبيته على Android، افتح الرابط الآمن HTTPS في Chrome ثم قائمة المتصفح واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية». يتطلب التثبيت HTTPS (أو localhost).
- يخزن Service Worker ملفات الواجهة فقط؛ لا يخزن طلبات API أو مفاتيح. التثبيت لا يحول خادماً محلياً إلى استضافة دائمة.

## إعدادات من الهاتف

من تبويب **الإعدادات** أدخل مفتاح Gemini أو Groq أو OpenRouter ورمز Vercel، ثم احفظ. المفاتيح ترسل إلى الخادم عبر HTTPS عند النشر العام وتُحفظ في `.env` على جهاز الخادم، ولا تعاد إلى المتصفح. الحقول الفارغة تترك القيم السابقة دون تغيير. حد الإصلاح قابل للضبط من 0 إلى 10 محاولات لكل أمر فاشل.

في بيئة عامة، لا تستخدم إعداد المفاتيح إلا بعد تفعيل الحماية بكلمة مرور قوية. لا تُضمّن المفاتيح في ZIP أو Git. تخزين المفاتيح داخل `.env` مناسب لتجربة شخصية، لكنه ليس مدير أسرار مؤسسياً.

## تشغيل محلي

المتطلبات: Python 3.10+، واتصال إنترنت لمزودي النماذج/البحث. على Windows شغّل `start.bat`؛ على Linux/macOS:

```bash
cp .env.example .env
chmod +x start.sh
./start.sh
```

افتح `http://127.0.0.1:7860`. المنفذ الافتراضي 7860 ويمكن تغييره بواسطة `PORT`. تشغيل محلياً يبقي الواجهة على loopback افتراضياً. لا تجعلها متاحة لشبكتك دون فهم المخاطر.

## إعداد استضافة Docker / Hugging Face Spaces

المشروع مهيأ لواجهة Docker على المنفذ 7860. في إعدادات Space أو مزود الاستضافة أضف **Secrets** التالية، ولا تضفها لملفات عامة:

- `APP_PASSWORD`: كلمة مرور طويلة وعشوائية للوصول إلى API والإعدادات.
- `PUBLIC_MODE=true`.
- مفاتيح النموذج، مثل `GEMINI_API_KEY`، عند الرغبة باستخدامه.

ثم أنشئ Docker Space وارفع ملفات المشروع. إعداد README يحدد `sdk: docker` و`app_port: 7860`. بعض المنصات المجانية تتوقف عند الخمول أو تستخدم قرصاً مؤقتاً، وقد تتغير سياساتها؛ لا تعتبرها استضافة دائمة. لا أستطيع إنشاء Space في حسابك أو ربط مستودعك دون بيانات دخول/صلاحية لهذا الحساب. تشغيل نسخة على رابط معاينة مؤقت لا يساوي نشر دائم.

في Docker، `PUBLIC_MODE=true` افتراضياً. إذا لم تضبط `APP_PASSWORD` سترفض API الطلبات. لا تنشر ببيانات افتراضية. استخدم HTTPS. المصادقة تضيف حاجزاً أساسياً فقط؛ للتعرض العام الدائم أضف تحديد معدل محاولات الدخول، سجلات أمنية، نسخاً احتياطية وتخزين أسرار مُداراً.

تشغيل Docker محلياً:

```bash
docker build -t autonomous-agent .
docker run --rm -p 7860:7860 -e APP_PASSWORD='ضع-كلمة-مرور-قوية' -e PUBLIC_MODE=true --env-file .env -v "$(pwd)/workspace:/app/workspace" autonomous-agent
```

## التنفيذ الآلي والإصلاح الذاتي

يتطلب زر **تنفيذ آلي** موافقة لكل مهمة، وينفذ حتى 10 خطوات، ويكتب ملفات أو يشغل أدوات من قائمة محدودة أو يجري بحثاً عاماً. أوامر `npm` وPython قادرة على تشغيل شيفرات خارجية؛ لذلك هذه الأدوات ليست sandbox أمنيّاً كاملاً. الإصلاح يعيد المحاولة حتى القيمة المحددة (0–10، الافتراضي 5)، ثم يتوقف. لا يضمن نجاحاً 100% ولا يعمل بلا توقف. النشر الخارجي يتطلب تأكيداً منفصلاً ولا يُفعل آلياً.

أداة البحث مبنية على DDGS، لا على API Google الرسمي. استخراج الصفحات قد يُرفض، والروابط المحلية/التحويلات تُمنع كإجراء احترازي. راع شروط المواقع وحقوق المحتوى. التقارير البحثية تحفظ كـ Markdown تحت `workspace/reports`.

## إعداد مزودات النماذج

تدعم `.env` المفاتيح والنماذج مفصولة بفواصل. استخدم مفاتيح تملكها ووفق شروط المزود؛ التناوب لا يزيل حصصهم. Ollama يحتاج تثبيتاً وتنزيلاً يدوياً للنموذج. لا توجد حصة مجانية مضمونة بلا حدود.

## الملفات

```text
backend/main.py       API، المصادقة الاختيارية، الإعدادات والوكيل
static/index.html     واجهة التطبيق
static/mobile.css     تنسيق الهاتف
static/pwa.js         التنقل والإعدادات/الدخول
static/manifest.json  بيانات PWA
static/service-worker.js  تخزين ملفات الواجهة فقط
static/icon-*.png     أيقونات التثبيت
static/history.js     سياق المحادثة المحلي
static/agent-ui.js    واجهة التنفيذ الآلي
workspace/            ملفات عمل المستخدم
```

ملف `.env` غير مضمّن في ZIP. المشروع للتجربة الشخصية؛ قبل استضافة عامة، راجع صلاحيات الأوامر، وفّر HTTPS ومصادقة قوية وحماية من محاولات الدخول، ولا تخزن بيانات حساسة دون حاجة.
